# KOBA Platform

Umbrella repo for the KOBA.GAMES sub-brand projects proposed in
[KOBA_PLATFORM_PROJECT_SCOPING.md](KOBA_PLATFORM_PROJECT_SCOPING.md) —
KOBA Bot, KOBA Core, KOBA Discord App, KOBA PC Plugin, KOBA Adaptive
Capacity, KOBAid Identity, KOBA Creator Ecosystem, and KOBA Live.

**KOBA Creator Engine has nothing to do with this project.** It's a
wholly separate repo (`~/Desktop/koba_creator_engine/`) with its own
scope and its own `ROADMAP.md` — not part of this umbrella.

As each sub-brand project moves from spec to real work, it gets its
own directory and ROADMAP.md here.
