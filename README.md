# KOBA Platform

Umbrella repo for the KOBA.GAMES sub-brand projects proposed in
[KOBA_PLATFORM_PROJECT_SCOPING.md](KOBA_PLATFORM_PROJECT_SCOPING.md) —
KOBA Core, KOBA Live, KOBAid Identity, the content builds (Casino &
Resort, Ferry Terminal, Theme Park, World Events, etc.), and the rest
of the sub-brands scoped out there.

The **KOBA Creator Engine** (the asset-generation toolchain those
content projects depend on) lives in its own separate repo, not here.

As each sub-brand project moves from spec to real work, it gets its
own directory and ROADMAP.md here.
